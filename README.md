# Project: Bloom & Grow Nonprofit Website

## 1. Project Overview
**Client:** Bloom & Grow (Urban Community Garden Nonprofit)
**Goal:** Create a clean, responsive "brochure" style website to showcase gardens and recruit volunteers.
**Tech Stack:** HTML5, CSS3, Bootstrap 5.

---

## 2. Design Guidelines
* **Vibe:** Organic, welcoming, trustworthy.
* **Color Palette:**
    * Primary: Deep Forest Green (Leaves/Nature)
    * Secondary: Warm Brown (Soil/Earth)
    * Accents: Orange or Yellow (Sunshine/Flowers - use for buttons)
* **Typography:**
    * Headings: Serif font (Classic, established feel).
    * Body Text: Sans-serif (e.g., Open Sans or Roboto - clean and modern).
* **Layout:** Spacious, using "white space" to avoid clutter.

---
